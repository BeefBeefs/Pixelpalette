Palette files use little-endian GBA RGB555. Tile data is written in 8×8 row-major tile order; 4bpp packs two pixel indices per byte.

GBA Notes

4bpp: 16 palette entries, 32 bytes per 8×8 tile
8bpp: 256 palette entries, 64 bytes per 8×8 tile
Palette: little-endian RGB555
Tile order: left-to-right, then top-to-bottom
